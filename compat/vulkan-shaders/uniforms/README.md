# Reflected native uniform blocks

Original GPL-3.0-only resource ABI helper for the Forge Vulkan port. `SpirvUniformBlock` reads actual compiled SPIR-V descriptor set/binding and block member decorations. It uses reflected offsets, array strides and column-major matrix strides without relying on optional debug names or recompiling a regex-derived declaration order. It supports 32-bit float/int scalars and vectors, column-major float matrices and one-dimensional fixed arrays. Missing, overlapping, reordered, repeated or unsupported layouts and wrong-type/arity/short/read-only writes reject before upload. It preserves input/output cursors. Module, ID and block-size bounds apply; this is not a complete SPIR-V validator or arbitrary shader resource implementation.

The real compiler regression uses the complete pinned repaired Iris compiler and official shaderc3.3.6 on Java17. Seven mixed members produce a192-byte block with offsets0/12/16/64/112/176/184 and16-byte matrix/array strides. Packed mat3, compact array and transposed matrix controls fail. Malformed layouts and writes are rejected. Run `tests/test_uniform_abi.py --download-reference --lwjgl-classpath CLASSPATH --report FRESH_JSON` after resolving `native-test-sdk/writeTestClasspaths`. `--export-spv FRESH_DIRECTORY` creates the private portable shader artifact; original GLSL is in `tests/gpu-reference-sources/reference-uniform-fragment.glsl`.

In actual Minecraft, Hari .13 uploads that reflected payload through a native dynamic UBO descriptor, draws and reads back all1024 pixels. Valid values render green. Changing one mat3 element updates the upload and renders red. Both outputs match every pixel, and the original four primitive/stencil cases pass in the same session. [Exact native evidence](../../../benchmarks/results/cumulative-foundation-20261005/proofs/iris-reflected-uniform-native-gpu-summary.json) records hashes and scope. Original owned mods were restored by SHA256, and no game native library was upgraded.

This helper is included in controller1.0.17 for the strictly owned diagnostic, not shipped as an independent play mod. A real provider still requires shader-pack transformations/name mapping, samplers/images, complete buffer lifetime, MRT/framebuffer passes, terrain/shadows/postFX and compute dispatch, as well as the Forge1.20.1 port. No FPS/startup/hitch gain or active Oculus/Iris/complete Flywheel acceptance follows from this bounded test.

Primary layout references: [Khronos shader memory layout](https://github.khronos.org/Vulkan-Site/guide/latest/shader_memory_layout.html) and [official SPIR-V grammar](https://github.com/KhronosGroup/SPIRV-Headers/blob/main/include/spirv/unified1/spirv.core.grammar.json). License: [GPL-3.0-only](LICENSE). No upstream or private shaderpack binary is redistributed.

`reflectStructured` explicitly opts into static nested structs with bounded depth/leaves. `fieldOrdinal` takes a path of member indices, retaining offsets and matrix/array strides from the compiled module. The existing `reflect` interface continues to reject nested structs. Original Flywheel's complete frame block reflects to 864 bytes/46 leaves; actual GPU culling consumes its frustum, view matrix and cull data. The new native regression validates paths, nested writes and cursor/matrix/integer behavior, and rejects a lost parent-offset mutation. [Native Flywheel implementation and precise scope](../../native-flywheel/README.md). Arrays of structs and nested arrays remain unsupported.
