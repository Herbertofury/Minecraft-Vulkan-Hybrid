# Performance experiments after native provider integration

Independent research supplied by the user on2026-10-14; reconciled against Hari55. These are proposed experiments, not measured Hari FPS or full-pack loading gains.2,000FPS is a0.5ms frame budget. Complete the original typed provider and actual full327 gameplay before claiming that target.

Hari55 already records original buffer-image uploads and framebuffer actions on the existing graphics command stream. Coherent VkBuffers retain recorded readers through original mapping, copy-on-write and deletion. Aligned RGBA bytes upload directly; signed/unaligned inputs use retained native repacking. The141-case original-chain regression preserves129 previous pixel hashes. A second upload-batching rewrite has no demonstrated benefit yet. Existing synchronous readback and older image-clear helpers still wait for real completion; the synchronous return contract must be preserved. The accepted launcher-helper gain is separate from full mod loading and frame time.

| Experiment | Current reconciliation and acceptance |
| --- | --- |
| Bounded timing/counters | Instrument actual upload bytes/copies/repacking/submits/waits, pipeline creation and descriptor allocation/write/bind boundaries. Measure first-use and repeated scenes before selecting a refactor. Keep telemetry bounded and compare separately with instrumentation disabled. |
| Staging reuse and upload retirement | Reuse only after completion; test wraparound, overlapping ranges, mapped reallocation, close/reload/cancel, upload-then-sample and untouched mips/aspects. Coherence does not remove GPU lifetime hazards. Keep required first draws correct. Start with the existing queue. [Synchronization examples](https://docs.vulkan.org/guide/latest/synchronization_examples.html), [wait-idle costs](https://docs.vulkan.org/samples/latest/samples/performance/wait_idle/README.html). |
| Precise barriers | Record resource/subresource access and transition causes. Remove a dependency only when access/layout/ownership history proves it redundant. Preserve observable contents; do not substitute UNDEFINED/DONT_CARE for a required load. [Khronos barriers](https://docs.vulkan.org/samples/latest/samples/performance/pipeline_barriers/README.html), [NVIDIA guidance](https://developer.nvidia.com/blog/vulkan-dos-donts/). |
| Descriptor reuse | Keys need layout, resource generation, view/sampler, offset/range and layout identity. Never mutate an in-flight set or confuse recycled public names with live resources. Test resize/reload/delete-recreate and simultaneous use. Keep the conventional correct path. [Descriptor management](https://docs.vulkan.org/samples/latest/samples/performance/descriptor_management/README.html), [Zink strategies](https://docs.mesa3d.org/drivers/zink.html). Zink is a reference, not an authorized pack addition. |
| Pipeline misses and warmup | Measure miss/creation latency; deduplicate complete-state keys and warm real encountered pipelines. Include shader content/translation, layouts, vertex/attachment/sample/non-dynamic state. No skipped draws or semantically different substitute while compiling. Separate cold/warm/corrupt cache/driver/reload tests. [Pipeline cache](https://docs.vulkan.org/samples/latest/samples/performance/pipeline_cache/README.html), [pipeline libraries](https://docs.vulkan.org/samples/latest/samples/extensions/graphics_pipeline_library/README.html), [DXVK experience](https://github.com/doitsujin/dxvk#graphics-pipeline-library). |
| Optional pipeline binaries | Evaluate after ordinary cache timing, only when supported. Persist device/driver compatibility metadata and recover by correct compilation. No cross-device portability claim. [Khronos pipeline binary sample](https://docs.vulkan.org/samples/latest/samples/extensions/pipeline_binary/README.html). |
| Allocations/recording/memory | Profile allocation and CPU stacks before pools/parallelism. Stack data cannot escape; asynchronous payloads need retained ownership. Do not parallelize mutable render-thread callbacks or reorder transparency/stencil. Track actual memory pressure before allocator changes; preserve texture/view/entity/animation quality. [LWJGL memory](https://blog.lwjgl.org/memory-management-in-lwjgl-3/), [command recording](https://docs.vulkan.org/samples/latest/samples/performance/command_buffer_usage/README.html), [VMA budget](https://gpuopen-librariesandsdks.github.io/VulkanMemoryAllocator/html/staying_within_budget.html). |

Correctness must include actual original provider call chains, window resize/minimize/restore, reload, GUI overlays, world switching, destruction/recreation, HDR/mips/depth/stencil/clipping and region-boundary transparency with moving cameras. [Historical transparency failure](https://github.com/CaffeineMC/sodium/issues/2132) is a test motivation, not a workaround to transplant. Use supported [VVL](https://github.com/KhronosGroup/Vulkan-ValidationLayers)/[GPU-assisted validation](https://github.com/KhronosGroup/Vulkan-ValidationLayers/blob/main/docs/gpu_validation.md) in correctness sessions; disclose instrumentation and benchmark a separately validated performance configuration.

Full-pack acceptance keeps all327 jars, features/fidelity, world/camera/settings/resolution/shaders/resource packs/JVM/driver matched. Record raw frame times, p50/p95/p99, defined1%lows, hitch/tick/input/CPU/GPU/GC/memory data, warmup/cache policy and repeated AB/BA order. Record concurrent GPU workload contamination without stopping other projects. Cross-check [PresentMon](https://github.com/GameTechDev/PresentMon) with engine timing; unavailable metrics are not zero. [RenderDoc](https://github.com/baldurk/renderdoc/blob/v1.x/docs/behind_scenes/vulkan_support.rst) is for rendering inspection, not shipping FPS claims. Do not change OS/security/scheduling settings to obtain telemetry.

Each adopted experiment needs baseline/candidate commits, exact scenario, raw evidence, correctness results and rollback. No gain is predicted here. Priority remains the actual URenderPassImpl/URenderPipeline/ManagedGlState/sampler/automatic GAME integration, then full327 native gameplay and measurement.
