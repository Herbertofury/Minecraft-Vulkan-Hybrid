# Native Flywheel batch

Hari `.16` includes a real Vulkan storage/compute/indexed-instancing implementation. It keeps Flywheel 1.0.5's 76-byte transformed instances, 28-byte model descriptors and 36-byte extended indexed draw commands. Original cull/apply/transformed shader components execute on the GPU. Storage bindings retain their original numbers; storage, frame uniforms and depth samplers use separate descriptor sets. Explicit host/compute/indirect/vertex barriers order writes, compaction and draws. Buffers are persistently mapped coherent memory, objects have a render-thread owner, and cleanup uses Hari's existing fence-delayed queue. Graphics pipelines use Hari's actual traditional render pass; the optional zero-handle path requires a device configured for dynamic rendering.

The integrated device enables `drawIndirectFirstInstance` only when supported, separately from `multiDrawIndirect`. The upload builder now uses explicit uncompressed float/integer texel footprints instead of returning zero for `R32_SFLOAT`. Unknown/block-compressed footprints reject. This does not implement every texture format or image operation.

The preceding Hari `.15` actual Minecraft 1.20.1/Forge 47.4.26 testing on the RTX 4090 compares every pixel in seven cases: three/one/zero instances, changed pose/tint/light, original cull target compaction, frustum rejection and sampled-depth rejection. All 24,576 pixels per case match an independent direct indexed draw reference. Nonzero first instance is one; command bytes outside the generated count remain intact. The sampled depth fixture contains uniform float depths; complete terrain depth-pyramid generation is still required. The original shaft JSON and both texture images come from the installed original Create 6.0.8 JAR, never substituted assets. See [runtime evidence](../../benchmarks/results/cumulative-foundation-20261005/proofs/flywheel-native-cull-gpu-summary.json).

Hari `.16` also caches actual depth/stencil/color pipeline variants and supplies dynamic stencil masks/reference. It rejects clipping without a stencil attachment. The pinned original Ponder default-method lifecycle draws native original shaft content with two distinct clips. All 24,576 pixels in each image match an independent CPU crop of the unclipped native reference; original cleanup restores every unclipped pixel. The seven compute/cull/instance controls still pass, making ten actual GPU cases. [Combined Ponder/shaft evidence](../../benchmarks/results/cumulative-foundation-20261005/proofs/flywheel-ponder-native-gpu-summary.json).

This is a working native rendering/compute component. It is **not a complete Flywheel backend or full Create/Ponder launch**. The original Java OpenGL backend, material/light LUTs, dynamic meshes, depth-pyramid generation, OIT, full Ponder/contraption scenes and Forge shader provider remain to be integrated. The renderer gate was not changed to admit these unfinished paths. No full-pack, active Oculus/Iris/shaderpack, startup/FPS gain or zero-hitch claim follows from this diagnostic. Original Create is restored afterward by SHA256.

From the repository root, build a fresh integrated tree and the marker-confined controller:

```powershell
python integration/dimensions/assemble.py ..\hari-native-build
.\source\gradlew.bat -p ..\hari-native-build :forge:build
.\source\gradlew.bat -p benchmarks/pack-control-forge build "-PmvhHariReference=C:\absolute\hari-native-build\forge\build\libs\harimt-forge-1.20.1-2.4.11-noxviola.16-dimensions-vulkan-hybrid-all.jar"
```

Resolve the isolated official compiler SDK with `source/gradlew -p compat/vulkan-shaders/native-test-sdk writeTestClasspaths`. With Java 17 on PATH, run `tests/compile_fixture.py --download-reference --lwjgl-classpath CLASSPATH --output FRESH_PRIVATE_DIRECTORY --create-jar ORIGINAL_CREATE_JAR --report FRESH_JSON`. Omitting `--create-jar` performs only the four actual shader compilations and structured frame regression. The complete pinned Iris reference compiler runs in a separate SDK process; Minecraft's LWJGL 3.3.1 native libraries remain unchanged. The CPU regression also rejects a mutation that loses parent-struct offsets. Private Create assets must stay local.

Only the task-owned UUID/three-key marker accepted by `NativeStencilSmoke` can run `FLYWHEEL_NATIVE_CULL_BATCH`. Supply the exactly pinned fixture in `mvh-flywheel-fixture`, use Hari `.15` and controller 1.0.21 for the seven-case route, or Hari `.16` and controller 1.0.22 with `FLYWHEEL_NATIVE_PONDER_BATCH` and the SHA256-pinned repaired Ponder hierarchy fixture for all ten cases, and write the existing two-key request plus that route. The controller exits normally after the proof and accepts no FPS. A fixture rebuilt on the tested Windows SDK must report `pinned_windows_gpu_fixture_matches: true`. Do not put the controller or private fixture in personal play profiles. Modrinth additions may retain prior disabled state: explicitly enable known existing files and check the complete active SHA256 set before launching.
