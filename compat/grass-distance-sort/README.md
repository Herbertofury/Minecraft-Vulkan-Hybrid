# Exact grass distance sort experiment

An actual native Vulkan JFR identified repeated stable section-priority sorting beneath the original Grassier Grass cache. The addon preserves its renderer, geometry, density, range, animation, light and rebuild behavior. Version 1.0.0 computes each original pure section distance once per sort. Its six native ABBAAB trials are retained in the [grass results](../../benchmarks/results/cumulative-foundation-20261005/native-grass-SUMMARY.json); validation is ongoing and the target is not yet met.

Development 1.0.1 additionally retains the exact input prefix and stable permutation separately for each of the two sort sites. It reuses the permutation only if every input key, count and all three raw camera double values match. Any membership/order/camera change recomputes the original pure distances. No mesh, world, frustum, animation, shader or resource state is cached. Thread-local owners and all scratch/input/permutation arrays are bounded to 65,536 entries per sort site; larger sorts fall back to temporary arrays. Failure invalidates the cache before propagating the original exception. This is a source experiment pending build and native runtime validation.

Only the inspected private `Grassier-Grass-1.4.5-Render-Performance-Fix-REPLACEMENT-2.jar` (SHA256 `91006e8220e65572d7e9e1e54b6058526c4adf908faedc750c9f19f13623df8c`) is supported. Original assets/source are not redistributed. The addon is GPL-3.0-only. Two ordinal-specific injection matches and an exact whole-JAR hash fail closed for unsupported versions. Minecraft resource metadata is format 15.

Build with Java 17: `source/gradlew -p compat/grass-distance-sort build`. Current output: `build/libs/mvh-grass-distance-compat-1.0.1.jar`. The 1.0.0 source remains available in the prior commit. Independent JDK stable-sort comparisons cover ties, NaN/infinity/signed zero, prefix bounds, scratch limits, repeated keys, camera changes, membership changes, exceptions and owner isolation. These verify semantic equivalence; they are not FPS estimates or full grass feature acceptance.
