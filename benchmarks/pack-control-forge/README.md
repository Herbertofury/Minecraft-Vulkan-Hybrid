# Disposable pack control

Source-built Forge 1.20.1 / Java 17 recorder and native grass play test, GPL-3.0-only. Build with `source/gradlew -p benchmarks/pack-control-forge build`. Resource metadata is format 15. This controller moves the camera, records, saves and exits automatically; use only marker-owned disposable test worlds, never the personal Noxviola profile.

Default mode retains all RenderTick END CPU intervals after 60 seconds of warmup and captures 30 seconds. These are not GPU timestamps or presentation timings. `-Dmvh.pack.grass.smoke=true` selects an ownership-checked bounded native play test instead: resource reload, original mesh/shader state, animation phase, real movement/trail state, stationary FOV widening/restoration, Nether and return. Smoke tests accept no FPS. Screenshots require visual review; all-style and shader-provider parity remain separate requirements. The caller archives worlds and restores the checksum-verified pristine copy before every run.

When the pinned native TRender helper is installed, grass smoke additionally opens EntityCulling's real settings UI, checks balanced actual scissor calls, closes it and verifies native grass resumption without leaked clipping state. It is still bounded by the same ownership/deadline checks and accepts no FPS.

Controller 1.0.11 also accepts one exact task-owned `mvh-chunk-purpose-request.json` schema. It restores no files itself; the runner must first restore the original checksum world and reject an already-generated target region. After 20 seconds in the fixed scene, it requests 144 Overworld chunks at x/z 1024..1035 through Minecraft's normal off-owner FULL future API. Region tickets and full/lit chunk verification run on the server owner. The wall timer ends when every future completes, before verification. Every section's block-state registry IDs and biome keys are hashed; entity/NBT/lighting-array parity is outside this digest. The mode has a 240-second deadline, records server tick interval tails, saves/exits normally and accepts no FPS. The runner archives the request/report before any subsequent default benchmark.

Five actual native chunk diagnostics completed all 144 FULL/lit chunks. The intended C2ME comparison stopped after its first pair: 2.73 seconds without versus 54.38 with C2ME. An earlier enabled probe took 46.74 seconds; disabled repeatability probes took 2.45/2.54 seconds. Digests also varied within the disabled baseline, and registry-ID mapping equality is unverified. This does not establish terrain corruption or a completed six-run causal regression. C2ME is disabled in the owned continuation until its purpose benefit and parity are established. The earlier UI and all-frame evidence retains the exact recorder versions used at capture time.

Controller1.0.15 adds an exact-owned non-FPS stencil request. `DIRECT_NATIVE_STATE` compares actual Vulkan images for clip/write-mask/disable. Optional `PONDER_DEFAULT_METHODS` requires the hard-pinned private component fixture outside mods and permits only the original four-interface hierarchy and two own bridge classes in its diagnostic loader; it never invokes Ponder mod entrypoints or omits Flywheel from a claimed full-mod test. All owned files/world copies must be prepared and archived by the caller. Production play files exclude this automatic controller.

Controller1.0.16 adds `IRIS_REFERENCE_SPIRV` to that strict owned diagnostic schema. Two hard-pinned portable compiler outputs are read from the owned profile root, used for actual shader module/pipeline/vertex-index draw and read back as a fourth exact1024-pixel case. Modules/pipelines use the renderer's deferred cleanup; CPU source buffers are released after module creation. No SDK DLL or provider is installed, and the controller remains excluded from play artifacts.

Controller1.0.17 adds the strict `IRIS_REFERENCE_UNIFORMS` diagnostic. It includes the original GPL reflected-ABI helper, pins the portable shader, uploads a192-byte native dynamic UBO and requires six exact GPU readbacks, including green valid data and red changed-matrix data. The isolated run restores its original active JARs; this controller remains excluded from Desktop play artifacts.
